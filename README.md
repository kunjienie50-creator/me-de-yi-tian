# me的一天

面向手机浏览器的一天规划原型：小猫陪你写下今天想做的事、把长期目标拆成节点、排进日程、计时打卡，晚上小结，第二天温和重启。暂时不想做的事可以先扔进「事件箱」，想起来再取出来。

> **这是可路演的原型，不是成品。** 没有登录、没有后端数据库；数据只存在当前浏览器里。
>
> AI 部分是可选的：本地 `npm run dev` 时通过 `server/ai.js` 调用 DeepSeek（拆解 / 次日重排 / 备注补一句），没配密钥或跑在线上静态版时，会自动回退到本地规则与预置样例。详见「接大模型」一节。
>
> 开发者请看 **[HANDOFF.md](./HANDOFF.md)**：交接说明、数据模型、Prompt 位置、已知问题与待办。

## 技术栈

- Vite 7 + React 19（JavaScript，非 TypeScript）
- 普通 CSS（无 Tailwind / CSS-in-JS / UI 组件库），单一全局样式表 `src/App.css`
- 无路由库：视图由 `src/App.jsx` 里的 `route` 状态切换
- 无状态管理库：`src/store.jsx` 用 `useReducer` + Context
- 小猫是内联 SVG + CSS 动画，没有图片资源依赖


### 如果安装阶段报 `spawn EPERM`

受限环境（例如某些沙箱）里 esbuild 的 postinstall 无法启动子进程，可用：



## 首页布局与小猫

首页从上到下：标题栏（标题下是一句广告语，点一下换下一句）→ 小猫（点一下会回应）→ 横向一周日历（每格一天，方块是一件事，颜色跟所属目标走）→ 「开始计时 / 睡前结算」两个大按钮 → 事件箱入口（有东西时显示前几件）→ 昨天没做完的提示（点它进重启）→ 今天要做的清单 → 长期目标。

- 日历默认排七天；本周剩余天数不够时自动只排到今天之后的几天。点任意一天会弹出那天要做什么。
- 没有「接下来」列表，也没有「一天回顾 / 温和重启」的按钮入口：回顾在底部导航里；重启只在昨天真有没做完的节点时，以一条提示出现，点「今天先不管这些」当天就不再打扰。
- 换小猫形象：`src/components/Cat.jsx` 顶部的 `CAT_SKINS` 就是形象表，改配色字段即可新增一只；要换成自己画的图，把 skin 写成 `{ id, name, kind: 'image', idle: '/cat/xxx.png', happy: ..., sleepy: ... }`，图片放进 `public/` 即可，代码不用动。设置页可以直接切换现有形象。

## 事件箱（暂时不做的事）

- 入口：首页「事件箱」卡片、或地址栏 `#box`。
- 随手记：输入一句话 → 「放进箱子」，会自动猜一个分类；箱子里的东西不算计划、不进进度、不会被催。
- 取出来：「放进今天」直接排到今天，「挑一天」选日期，之后就变成正式任务。
- 从计划里放进去：睡前结算点「没做完」会出现「先收进事件箱」；重启草案的「建议放下」里也有「放进事件箱」。两条路都只是把任务状态改成 `boxed`，任务本体保留在项目里，不算删除。

## 分类标签

- 默认六类：📚 学习&工作 / 🌙 睡觉 / 🎮 娱乐 / ☕ 社交 / 🏃 运动 / 🧺 生活琐事（`src/lib/tags.js` 的 `DEFAULT_TAGS`）。
- 新建任务、新建长期目标时按标题用关键词规则先猜一个（`guessTagId`），可以改，也能在「+ 新分类」里自己加（存在 `state.customTags`）。
- 标签会带到节点上：任务行显示分类徽标，目标卡和排期页显示项目分类；目标配色仍按项目顺序取色，两者互不冲突。

## 序号、优先级与「前驱不能排到后继之后」

- 拆解结果里每个节点都有 `seq`（顺序号）和 `priority`（P1 先做 / P2 接着做 / P3 收尾）；`src/lib/decompose.js` 的 `guessPriority()` 按动词猜（定/确认/列/梳理 → 高；检查/收尾/复盘/导出 → 低），`validateDraft()` 会按数组顺序重编号，模型（或样例库）改不了先后。
- 排期时按 `seq` 排序，并用 `src/lib/schedule.js` 的 `clampToNeighbors()` 把日期钳在「前一个节点的日期 ~ 后一个节点的日期」之间：把 2 号拖到 4 号后面会被拦住，提示「它后面还有「列一份步骤清单」（10月26日），不能排到它之后」。
- 已保存的节点如果因为历史数据违反顺序，排期页顶部会用 `orderConflicts()` 列出来，不会静默改。

## 新建长期目标的流程

1. 点「新建长期目标」→ 一个弹窗只问一句话（示例 chips 可点）→ 「开始拆解」。
2. 「确认清单」：目标名、分类、每个节点的序号 + 名字 + 优先级 + 估时，能加、能删、能改，也能「太粗了 / 重新拆一次 / 太细了」重拆。
3. 「排进日历」：先钉截止日（📌「10月30日 周五 钉住」），节点变成彩色方块落在日历里（颜色按优先级，方块上只写序号）；**拖方块**到某天，或**先点方块再点日期**；点「重排」回到规则均匀排布。前驱约束在这里同样生效。
4. 「就按这个日期，创建目标」→ 节点带着日期、序号、优先级、分类一起生成，跳到排期页可以继续微调。

## 计时忘了停怎么办

- `src/lib/timer.js` 的判定：一条计时已经跑了 5 小时以上，**或者**开始时间不是今天（跨日），就算「可能忘了停」。
- 首页顶部会出现一条提示条「上次那条计时好像忘了停」+ 「补录 / 先不管」。点「先不管」会把这条计时的 id 记进 localStorage（`me-de-yi-tian.leak-dismissed.v1`），刷新也不再弹；真的停了计时后自动清掉。
- 补录时只问一件事：**「实际几点结束的」**（`datetime-local`，只能填开始之后、现在之前）。时长按你填的时间算，不会用「当前时间」倒推；默认只记录时间不点亮节点，勾选「这次算点亮那条节点」才会改进度。

## 接大模型（DeepSeek）

模型只介入三处，都是「生成建议 → 本地校验 → 你确认」：

| 场景 | 前端调用 | 代理 | 离线兜底 |
| --- | --- | --- | --- |
| 一句话拆成清单 | `aiDecompose()`（`src/lib/ai.js`） | `/api/ai/decompose` | `decompose()` 样例库 |
| 昨天没做完的重排草案 | `aiRestart()` | `/api/ai/restart` | `buildRestartDraft()` 规则表 |
| 任务备注补一句 | `aiNote()` | `/api/ai/note` | 不补，提示你手写 |

怎么开：

1. 复制 `.env.example` 为 `.env`，填 `DEEPSEEK_API_KEY=sk-...`（`.env` 已被 git 忽略）。
2. `npm run dev` 重启（配置只在启动时读一次）。设置页 →「模型」面板会显示「已连接 · deepseek-chat」。
3. 没填 key、代理 404、超时、模型返回非法 JSON —— 都会自动降级成离线规则，并在界面上标出「离线规则生成」和原因。

为什么要有这个本地代理：密钥只留在 Node 进程里（`server/ai.js`），永远不下发到浏览器；线上静态版没有这个代理，所以线上永远走离线规则，不会暴露任何 key。

模型输出不会被直接写进你的数据：拆解的清单会重排 `seq`、补全分类和估时；重排草案会丢弃越界项、把漏掉的节点补成「需要你决定」；所有改动仍然要你勾选、点确认。

想验证界面路径但暂时没有 key：`.env` 里加 `DEEPSEEK_MOCK=1`，代理会返回固定样例。

## 产品边界（原型刻意守住的规则）

- **进度只数节点**：不算百分比，`已完成节点数 / 节点总数`。
- **AI 不排日期**：拆解只给清单和估时；均匀排期由规则完成，截止日是硬约束，AI 不改。
- **写之前先给草案**：拆解、重启都是「草案 → 校验 → 你勾选确认 → 才写入」，没勾的保持原样。
- **不静默迁移**：未完成节点只有两个后移来源——你自己拖动，或采纳重启草案。锁定节点谁都动不了（手动拖动也会被拦）。
- **取消 ≠ 删除**：建议取消需要你逐个二次确认，任务本体留在项目里；原型不提供长期子任务的永久删除入口。
- **未回答 = 未知**：睡前没点的条目记为「状态未知」，不推断成没做完，也不责备；没做完的事不进分享卡。
- **睡前结算可跳过**：跳过不删任何任务，只是留了一条 `skipped` 记录。
- **照片只在本机**：存在 IndexedDB，不上传；分享/导出默认不带，需要显式勾选并二次确认。
- **漏停不猜**：计时忘记结束，下次打开只问「真实结束时间」，不自动结束。

## 演示走位（约 3 分钟）

1. **今天**：点标题下的广告语换一句；点一下小猫（它会回应）；看一周日历的方块颜色，点某一天看那天的安排。
2. **事件箱**：点「事件箱」卡片 → 随手记一句「报名周末的陶艺课」→ 看它自动归类 → 点「放进今天」→ 回首页看它出现在今天清单里，带分类徽标。
3. **重启**：点「昨天还有 2 件没做完」→ 回答三问中任意几问（或直接点「今天先不管这些」看它是怎么退出的）→ 生成草案 → 在「建议放下」里把一件放进事件箱、只勾一部分 → 应用；再回排期页点「撤销」，证明可以回退。
4. **目标**：新建长期目标 → 弹窗里写「练完一套全身力量训练」→ 确认清单（看分类被猜成「运动」，节点带 1/2/3 序号和 P1/P2/P3）→ 下一步钉截止日 → 把第 5 号方块拖到别的日期，再把第 2 号往后拖看被拦下的提示 → 创建。
5. **排期**：把某个节点推到隔壁天、用「⇤」堆叠、锁一个节点再点箭头（会被拦住），然后撤销。
6. **计时**：点首页「开始计时」→ 选一条任务 → 看时钟自己在走（不用刷新）→ 结束 → 勾「点亮这个节点」并写一句纪念。想试漏停提示：把 `me-de-yi-tian.state.v1` 里 `timer.startedAt` 改成 6 小时前再刷新，首页顶部会出现提示条，点「补录」填一个真实结束时间，看记录里的小时数是按你填的算的。
7. **睡前**：逐条点「点亮了 / 没做完 / 不想说」→ 对没做完的点「先收进事件箱」试一次 → 保存 → 看收尾动画 → 进回顾。
8. **回顾**：切到昨天看降级说明；点「分享这一天」看固定样片，打开照片开关（会出现二次确认）。
9. **设置**：切换小猫形象 → 看本地数据体积 → 导出 JSON → 最后再点「重置演示数据」回到起点。

在线版是 `gh-pages` 分支上的静态构建产物，`main` 只放源码。改完代码后重新发布：

```bash
npm run build
rm -rf ../pages-build && mkdir ../pages-build && cp -r dist/. ../pages-build/
cd ../pages-build && git init -b gh-pages && git add -A \
  && git commit -m "deploy" \
  && git remote add origin https://github.com/kunjienie50-creator/me-de-yi-tian.git \

```

## 已知限制

- 演示拆解只覆盖少量样例主题（路演、论文、健身、英语、作品集…），其余走通用模板，不会真的理解你的输入。
- 没有多端同步、没有账号、没有通知；「计时浮层」是页面内浮条，不是系统级悬浮窗。
- 分享是文字样片，不生成真正的图片文件；真实版才会渲染成卡片。
- 长期子任务暂不提供永久删除入口（符合产品当前边界）。
- 一天回顾还是旧版静态卡片，动画方案定下来后会整体重做；目前只保留底部导航入口。
- 未完成节点的「次日重排」只做成首页提示，不是常驻入口；点过「先不管」后当天不再出现。
- 分类和优先级都是关键词规则猜的（不是模型），偶尔会猜偏；猜偏了在分类 chips 里点一下就好。
